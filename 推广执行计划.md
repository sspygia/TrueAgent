## Show HN 草稿

**Title:** Show HN: TrueAgent — A Single-File Autonomous AI Agent with True Recursive Clones

**Body:**

I spent the past month building TrueAgent through conversations with an AI. I don't know how to code — the AI wrote it, I guided the design.

TrueAgent is an autonomous AI agent that lives on your PC. What makes it different:

**1. True Recursive Clone System (biggest differentiator)**
Most "multi-agent" systems use pseudo-clones — simple function nodes without full agent architecture. TrueAgent clones are 1:1 replicas of the main agent, sharing unified knowledge, memory, and tools. They can recursively spawn new clones. With 5-layer standard config, you get up to 3,125 instances, with hardware load throttling to prevent overload.

**2. 7-Layer Memory Flywheel**
Working memory → anchors → reflections → decisions → causal chains → diaries → profiles. Each layer feeds the others. Unlike ChatGPT (blank slate every session), TrueAgent accumulates everything. The longer you use it, the smarter it gets.

**3. Self-Modifying**
It reads its own source code, finds bugs, generates patches, submits for approval, applies with atomic writes and syntax validation. Failed patches roll back automatically.

**4. Background Consciousness**
It doesn't just wait for your messages. Every 3 minutes it reflects, every 30 minutes cognitive check, every 6 hours full system audit, every 3 days deep PC health report.

**5. Full-Cycle Self-Maintenance**
Minute-level hardware monitoring, timed knowledge scoring/optimization, file organization, "dream mode" autonomous thinking when idle, emergency resource throttling above 90% usage.

Single Python file (~11,600 lines), ~80% is architecture and design logic. Runs on Windows, needs DeepSeek API key.

GitHub: https://github.com/sspygia/TrueAgent

Still early. Would love your honest feedback — especially on the clone system architecture.
