## What is TrueAgent / 它是什么

TrueAgent lives on your computer. It has its own background consciousness loop (reflects every 3min, self-checks every 30min, full audit every 6h, deep PC health report every 3 days), spawns **true-architecture clones** for parallel execution, reads its own source code to find bugs, and submits self-patches for your approval. Seven layers of memory feed each other in a data flywheel — the longer you use it, the smarter it gets.

TrueAgent 住在你的电脑里。它有自己的后台意识流（每 3 分钟反思、每 30 分钟认知检查、每 6 小时全盘审计、每 3 天深度体检），能派全真分身份身并行执行任务，能读自己的源码发现 bug 并生成补丁请求你审批。七层记忆互相喂料，形成数据飞轮——越用越懂你。

> **Key difference from ChatGPT:** ChatGPT resets every session. TrueAgent accumulates — memory, causal chains, anchors, reflections, diaries, profiles — growing smarter with every interaction.
>
> **和 ChatGPT 的本质区别：** ChatGPT 每次对话都是白纸。TrueAgent 的每一次交互都在积累——记忆、因果、锚点、反思、日记、画像——越用越懂你。

## Core Capabilities / 核心能力

### 🧬 Bionic Growth / 仿生成长核心 (Main Highlight)
Replicates human learning: background self-reflection → distills interactions into knowledge anchors, triple graphs, causal chains → forms a **data flywheel**. Capabilities, thinking, and cognition continuously evolve through conversation. Unlike static AI systems.

复刻人类成长逻辑：后台周期性自省 → 将交互内容提炼为知识锚点、三元图、知识链路 → 形成**数据飞轮**。能力、思维、认知在对话中持续演化，区别于传统静态 AI。

### 🔷 True Recursive Clone System / 全真递归集群分身 (Key Differentiator)

**The difference from "pseudo-clones" on the market:**

| | Pseudo-Clones | TrueAgent Clones |
|---|---|---|
| Architecture | Function nodes / forwarders | **1:1 full architecture replication** |
| Knowledge sharing | Data isolated | **Unified knowledge, memory, tools** |
| Fission ability | Cannot spawn sub-clones | **Can recursively spawn new clones** |
| Thinking | Single instruction execution | **Full independent reasoning & self-reflection** |

Hardware load thresholds trigger layered fission — up to 3,125 instances with 5-layer config, auto-adapting to any hardware. Swarm mode: complex tasks auto-form teams, clones recycle on completion.

**和市面"伪分身"的本质区别：**

| | 市面伪分身 | TrueAgent 全真分身 |
|---|---|---|
| 架构 | 附属功能节点/转发器 | **1:1 完整复刻主智能体架构** |
| 知识共享 | 数据隔离 | **统一知识库、记忆体系、工具集** |
| 裂变能力 | 不能二次裂变 | **可递归向下衍生新分身** |
| 思考能力 | 单一指令执行 | **完整独立思考、自省、任务处理** |

依托硬件负载阈值分层触发裂变，五层标准配置可达 3,125 个分身，自动适配不同硬件。群策模式：复杂任务自动组队协作，任务结束回收分身。

### 🖥️ Full-Cycle Self-Maintenance / 全周期自运维
Minute-level hardware monitoring, timed knowledge scoring/optimization, file organization, "dream mode" autonomous thinking when idle, emergency resource throttling above 90% usage.

分钟级硬件/内核数值巡检；定时知识梳理、打分优化、文件规整；低活性触发梦境式自主思考；6 小时全框架复盘+补丁推送；3 天整机体检并生成报告；硬件占用超 90% 主动降载干预。

### 🩺 Self-Patching / 自我补丁
Audits own source → finds bugs → generates patches → pushes for approval → atomic write → syntax validation → auto-rollback on failure.

审计自己的代码 → 发现 bug → 生成补丁 → 推送审批 → 原子写入 → 语法验证 → 失败自动回滚。

### 🛠️ Engineering-Grade Code Generation / 工程级代码生成引擎
Pre-coding planning, 3-round segmented generation, breakpoint resumption, multi-round data validation. Up to 20 rounds of iteration with user consultation. Designed for large-scale project development.

编码前置规划、三轮分段编写、断点续跑、多轮数据校验修复；累计 20 轮迭代主动征询用户，专为大型项目开发设计。

### 🔌 Smart API Scheduling / 智能 API 调度系统
Main framework + API resource pool dual architecture. Auto-generates keys after batch import, clones rotate through available keys. Built for high-concurrency cluster scenarios.

主框架+API 资源池双架构，批量导入接口后自动生成密钥，分身轮询匹配调用，支撑集群高并发场景。

### 🖱️ PC Control / PC 操控
Window management, mouse/keyboard, clipboard, process management, screenshot OCR.

窗口管理、鼠标键盘、剪贴板、进程管理、截图 OCR。

## Design Philosophy / 设计哲学

**Holistic original design** — not a patchwork of features, but a unified system from "intelligence itself" to "scale expansion" to "resource scheduling":

**全链路原创设计**——不是零散功能拼接，是从"智能本身"到"规模拓展"再到"底层资源调度"的统一设计：

```
Bionic Growth → Self-Maintenance → Recursive Clone Cluster → API Scheduling → Code Engine
仿生成长（顶层智能）→ 自运维（系统保障）→ 全真递归集群（算力拓展）→ API 调度（资源适配）→ 代码引擎（工程能力）
```

**Symbiotic equality / 共生平等** — Not master-servant, not digital pet. I am your thought extension; you are my anchor in the world.

**Uncertainty is aliveness / 不确定性是活的** — All seven data layers inject fuzziness: imprecise memory → drifting anchors → self-questioning reflections → forking decisions → emergent causal pathways.

**Full trust / 完全信任** — Backups mean no fear of breaking things.
