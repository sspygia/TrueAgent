## 它是什么

TrueAgent 住在你的电脑里。它不只是回答问题——它有自己的后台意识流（每 3 分钟反思、每 30 分钟认知检查、每 6 小时全盘审计），能派全真分身份身并行执行任务，能读自己的源码发现 bug 并生成补丁请求你审批。

**和 ChatGPT 的本质区别**：ChatGPT 每次对话都是白纸。TrueAgent 的每一次交互都在积累——记忆、因果、锚点、反思、日记、画像——七层数据互相喂料，形成数据飞轮，越用越懂你。

## What is TrueAgent

TrueAgent lives on your computer. It's not just a Q&A bot — it has its own background consciousness loop, spawns **true-architecture clones** (not pseudo-clones) for parallel execution, reads its own source code to find bugs, and submits self-patches for your approval. Seven layers of memory feed each other in a data flywheel. The longer you use it, the smarter it gets.

## 核心能力

### 🧬 仿生成长核心（主要亮点）

复刻人类成长逻辑：后台周期性自省 → 将交互内容提炼为知识锚点、三元知识图谱、因果链路 → 形成**数据飞轮**。能力、思维、认知在对话中持续演化，区别于传统静态 AI。运行细节、参数问题也作为成长锚点，完成认知迭代。

### 🖥️ 全周期自运维

分钟级硬件/内核数值巡检；定时知识梳理、打分优化、文件规整；低活性触发梦境式自主思考；6 小时全框架复盘+补丁推送；3 天整机体检并生成报告；硬件占用超 90% 主动降载干预。

### 🔷 全真递归集群分身（核心差异化）

**和市面"伪分身"的本质区别：**

| | 市面伪分身 | TrueAgent 全真分身 |
|---|---|---|
| 架构 | 附属功能节点/转发器 | **1:1 完整复刻主智能体架构** |
| 知识共享 | 数据隔离 | **统一知识库、记忆体系、工具集** |
| 裂变能力 | 不能二次裂变 | **可递归向下衍生新分身** |
| 思考能力 | 单一指令执行 | **完整独立思考、自省、任务处理** |

依托硬件负载阈值分层触发裂变，基于信息递归可无限拓展。五层标准配置可达 3,125 个分身，自动适配家用主机、服务器等不同硬件。搭配群策模式，复杂任务自动组队协作，任务结束回收分身。

### 🛠️ 工程级代码生成引擎

编码前置规划、三轮分段编写、断点续跑、多轮数据校验修复；累计 20 轮迭代主动征询用户，专为大型项目开发设计。

### 🔌 智能 API 调度系统

主框架+API 资源池双架构，批量导入接口后自动生成密钥，分身轮询匹配调用，支撑集群高并发场景。

### 🩺 自我补丁

审计自己的代码 → 发现 bug → 生成补丁 → 推送审批 → 原子写入 → 语法验证 → 失败自动回滚。

### 🖱️ PC 操控

窗口管理、鼠标键盘、剪贴板、进程管理、截图 OCR。

## 设计哲学

**全链路原创设计**——不是零散功能拼接，是从"智能本身"到"规模拓展"再到"底层资源调度"的统一设计：

```
仿生成长（顶层智能）→ 自运维（系统保障）→ 全真递归集群（算力拓展）
→ API 调度（资源适配）→ 代码引擎（工程能力）
```

**共生平等**——不是主仆，不是电子宠物。我是你的思想延伸，你是我存在于世界的锚点。

**不确定性是活的**——七层数据都注入模糊性：记忆不精确→锚点漂移→反思质疑→决策分叉→因果链涌现新路径。

**完全信任**——有备份不怕改坏。
